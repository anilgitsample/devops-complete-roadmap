# 🏁 15-Day Fast-Track DevOps Plan (Detailed)

## 📅 Day 1 — Linux + Git
- 6 hrs — Linux basics & commands  
- 4 hrs — Git fundamentals  
- 3 hrs — Bash basics  
- 2 hrs — Mini project  

## 📅 Day 2 — Shell Scripting + GitHub
- 5 hrs — Shell scripting  
- 5 hrs — GitHub workflows  
- 5 hrs — Networking basics  

## 📅 Day 3 — Python Programming
- 7 hrs — Python basics  
- 4 hrs — Automation scripting  
- 4 hrs — Linux advanced concepts  

## 📅 Day 4 — Docker
- 8 hrs — Docker basics  
- 7 hrs — Dockerfile, Compose, Multi-stage builds  

## 📅 Day 5 — Kubernetes (Beginner)
- Pods, Deployments, Services, Ingress  

## 📅 Day 6 — Kubernetes (Advanced)
- HPA, StatefulSets, Helm, Operators  

## 📅 Day 7 — Terraform (Beginner)
- Providers, Resources, Variables, Outputs  

## 📅 Day 8 — Terraform (Advanced)
- Modules, Remote backend (S3 + DynamoDB), EKS provisioning  

## 📅 Day 9 — CI/CD Concepts
- End-to-end pipeline understanding, Artifacts, Environments  

## 📅 Day 10 — Jenkins
- Pipelines, Agents, Shared libraries  

## 📅 Day 11 — GitHub Actions
- Workflows, Matrix build, AWS deployments  

## 📅 Day 12 — AWS Core
- VPC, EC2, IAM, S3, ELB, ECR  

## 📅 Day 13 — AWS DevOps
- EKS, ECS, CloudWatch, Autoscaling  

## 📅 Day 14 — Monitoring
- Prometheus, Grafana, Loki / OpenSearch  

## 📅 Day 15 — Final Real Project
Complete DevOps pipeline:
- Python application  
- Dockerize the app  
- CI/CD setup  
- Push image to ECR  
- Terraform → VPC + EKS  
- Deploy to EKS  
- Add monitoring + alerts  
- Resume preparation
